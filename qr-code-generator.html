QR code generator

Make a QR code for a website, Wi-Fi network, business card, email, phone number or SMS. Pick colours and style, then download a sharp PNG or a scalable SVG for print. These codes never expire.

Encoded:

Static QR codes that never expire

Many "free" QR generators create dynamic codes that point to their own short link. They stop working when a trial ends and they track every scan. This generator makes static codes: your link or data is stored inside the pattern itself, so the code works forever and nobody tracks who scans it. The code is generated in your browser.

What each type does when scanned

  • Website: opens the link in the phone's browser.
  • Wi-Fi: joins the network without typing the password. Great for guests, cafés and Airbnbs.
  • Contact card: offers to save your name, phone, email and website to contacts.
  • Email / SMS / Phone: opens a pre-filled email, text message or call.

Printing tips

  • Download the SVG for print. It stays perfectly sharp at any size.
  • Print at least 2 × 2 cm (0.8 in); for posters, make the code about one tenth of the scanning distance.
  • Keep a dark code on a light background with the standard quiet zone. Inverted or low-contrast codes fail on many phones.
  • Use High error correction if the code may get scratched or if you'll place a small logo on top.
  • Always test with two different phones before printing in bulk.

Frequently asked questions

Do these QR codes expire?

No. They are static, so the information is inside the code and it works forever.

Can I track scans?

Not with static codes. That is by design: there is no middleman and no tracking.

Is it free for commercial use?

Yes. Use the codes on packaging, menus, flyers and business cards.

Why won't my QR code scan?

Usually low contrast, a missing quiet zone, or printing too small. Use dark on light, keep the standard margin and print larger.
