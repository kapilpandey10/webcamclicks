Password generator

Create strong, truly random passwords using your browser's cryptographic random generator. Choose the length and characters, see how strong each password is, and copy it straight into your password manager.

What makes a password strong?

Length matters most. Every extra character multiplies the number of possible passwords, while adding symbols helps less than people think. A random 20-character password using upper and lower case, numbers and symbols has about 130 bits of entropy, far beyond what any attacker can brute-force. Randomness also matters: passwords people invent follow patterns (names, years, "!" at the end) that cracking tools try first.

How this generator works

Passwords are created with crypto.getRandomValues, the cryptographically secure random number generator built into your browser, using rejection sampling so every character is equally likely. At least one character from each type you select is included, and the result is shuffled. Nothing is stored, logged or sent anywhere. Close the page and the password exists only where you saved it.

Good password habits

  • Use a different password for every account, so one breach doesn't unlock the rest.
  • Keep them in a password manager (the one built into your browser or phone is fine) instead of memorising them.
  • Turn on two-factor authentication or passkeys for email, banking and social accounts.
  • Use "avoid look-alikes" when you'll need to type the password by hand, for example a Wi-Fi password.

Frequently asked questions

Is it safe to generate passwords online?

Here, yes: the password is created in your browser and never transmitted. You can even disconnect from the internet after the page loads and it still works.

How long should my password be?

At least 16 characters for important accounts. Length adds more security than complexity.

What is entropy?

A measure of how unpredictable a password is, in bits. Each extra bit doubles the guesses an attacker needs. 80+ bits is very strong.

Do you store generated passwords?

No. Nothing is saved or sent anywhere.
