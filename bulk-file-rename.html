Rename rules

Rename many files in three steps

  1. Add your files. Drag them in, choose a folder, or in Chrome and Edge open a folder to rename files where they are.
  2. Set the rules. Type a pattern using the tokens below, add find & replace, change the case or replace spaces. The preview updates instantly and warns you about duplicate names.
  3. Apply. Download the renamed copies as a ZIP (works in every browser), or press Rename files to rename them inside the folder you opened.

Pattern tokens

  • {name}: the original file name without its extension.
  • {n}: a running number using the start, step and digits you set. Use {n:2} to force two digits.
  • {date} and {time}: the file's last-modified date (2026-05-14) and time (09-41-07).
  • {folder}: the name of the folder the file came from.

Popular recipes

  • Holiday photos in order: pattern Italy-2026-{n}, order by date modified → Italy-2026-001.jpg, Italy-2026-002.jpg…
  • Date-stamped scans: {date}_{name} → 2026-03-02_invoice.pdf.
  • Web-friendly names: keep {name}, case kebab-case, extension lowercase → my-holiday-photo.jpg.
  • Remove camera prefixes: find IMG_, replace with nothing.
  • Regular expressions: tick "Use regular expression", find (\d{4})(\d{2})(\d{2}) and replace with $1-$2-$3 to format dates.

Your files are read locally and never uploaded. Renaming in place uses your browser's built-in File System Access permission, which you grant for one folder at a time.

Frequently asked questions

Does it upload my files?

No. Files are read by your browser and renamed or zipped on your device.

Can it rename the original files instead of making a ZIP?

Yes, in Chrome and Edge on desktop: choose "Rename files in a folder", allow access to the folder, review the preview and press Rename files. Other browsers can download a ZIP of renamed copies.

How many files can I rename at once?

Thousands. The preview shows the first 500 rows to stay fast, but every file is renamed.

Can I undo a rename?

Downloading a ZIP never changes your originals. When renaming in place there is no automatic undo, so check the preview first; you can rename back with a find & replace.

Why are some names marked as duplicates?

Two files would end up with the same name. Add {n} to the pattern so each file gets a unique number.
